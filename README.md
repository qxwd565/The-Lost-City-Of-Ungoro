# HSdeck The Lost City Of Ungoro 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## README: API 편집 지침 (2026-11-14)

- 공개 API의 카드 관련 파일은 `cards.json` 목록, `data/<CARD_ID>.json` 한국 날짜별 카드 정보·변경 이력, `art/` 일반 원화, `golden/` 황금 원화/애니메이션, `frame/` 프레임·셰이더·텍스처입니다. 토큰을 포함한 카드 ID·DBF ID와 원본 자산 링크를 보존합니다.
- `render.json`, `history.json`, `*-date.json` 중복/호환 집계 출력은 더는 공개 커밋하지 않습니다. 빌드가 생성해도 테스트용 임시 파일로 취급합니다. 사용하지 않는 schema/호환 래퍼를 추가하지 않습니다.
- 기존 카드 원본이 날짜 키 형식이 아닐 경우 최초 사용일의 근거와 카드 필드를 보존하여 무손실 변환해야 합니다. 한국 실사용일 기준(베타 북미 시간 환산, 모험 실제 지구 개방일, 이벤트 개시, 토큰 생성 가능 시점)을 적용합니다.
- 오기입된 기존 날짜는 새 키 추가로만 덮지 말고 제거 후 통합합니다. 후속 날짜는 바뀐 필드만 작성하며 표시 개행은 `<br></br>`입니다. 황금·프레임 원본 바이너리/재질은 변형하지 않습니다.
- `release-policy.json` 및 실제 필요한 빌드/검증 `tools/`, `.github/`는 참조를 확인한 후 정리합니다.
